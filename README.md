# Memo
Claude Opus 5.5의 바닐라 버전의 애니메이션 예제를 보고는,
- https://codepen.io/editor/ChetasLua/pen/01a0cadf-5b81-756f-8647-8cf5a47e7adf

역시 Opus 5.5로 위 예제를 분석해보고, 최소 버전의 씨앗 예제를 만들었다. 

그 씨앗 구조를 기초로 Ball을 튕기는 게임을 제작했다.

애니메이션처럼 보이는 장면에서 상호작용이 발생하고, 자연스럽게 게임으로 이동하는 표현물이다.
